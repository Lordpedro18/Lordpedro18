# Sistema de Reequilibrio de Portafolio en Python

Este script implementa una clase `Portfolio` para gestionar un portafolio de inversión que realiza reequilibrios automáticos basados en:
- **Desviación de asignaciones**: Solo ejecuta un rebalanceo si la diferencia entre el objetivo y la realidad supera el **2%**.
- **Costos de transacción**: Determina si el rebalanceo es rentable considerando los costos por activo.
- **Liquidez del mercado**: Limita las órdenes para que no superen el **0.1%** del volumen negociado en la última hora.

### **Cómo funciona**
1. **Se inicializa el portafolio** con las posiciones actuales, asignaciones objetivo, costos de transacción y volumen negociado.
2. **Se calcula la asignación actual** en relación con el valor total del portafolio.
3. **Se verifica si el rebalanceo es necesario** (si la desviación es mayor al umbral de 2%).
4. **Se comparan costos de transacción** para evitar operaciones no rentables.
5. **Se filtran las órdenes** para que no excedan el 0.1% del volumen de mercado.
6. **Se ejecuta el rebalanceo** solo si cumple todas las condiciones anteriores.

### **Ejemplo de ejecución**
El portafolio contiene **IVV US y TLT US** con una asignación objetivo del **50%-50%** y aplica restricciones de liquidez y costos.
